# Python Contact Book

I created a simple terminal-based contact book using Python.

## Features

- Add contacts
- Update contacts
- Delete contacts
- Search for contacts
- Display all contacts

Contact data is stored in a JSON file. The file is created automatically when you add the first contact.

## Why I Used Phone Numbers as Keys

I used phone numbers as keys in my dictionary because every phone number is unique. If I used names as keys, people with the same name could cause problems. For example, when deleting a contact, I could accidentally delete the wrong person. Using phone numbers allows me to find, update, or delete the exact contact I want.

## How to Run

Open a terminal in the project folder and type:

```
python Contact_book.py
```

## Note

The app interface is in Azerbaijani. The names and phone numbers are fictional and are only used for testing.
